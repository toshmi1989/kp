# Генератор коммерческих предложений

Веб-платформа для АНО «ННЦ фармаконадзора»: быстрое создание КП в фирменном
бланке и ведение реестра услуг (цены, описания, этапы и сроки).

## Как это устроено

- **Документ собирается из настоящего фирменного бланка.** Мастер-шаблон
  (`backend/templates/kp_master.docx`) сделан из Word-файла компании: логотип,
  шапка, подпись директора, шрифты и оформление таблиц — оригинальные.
  При генерации меняются только значения: адресат, услуги, цены, этапы.
- **Один шаблон с условными блоками:** таблица этапов появляется, только если
  у услуги есть детализация; строки-группы («МОДУЛЬ 1…»), примечания и сноски —
  только если заполнены.
- **Снимок КП.** При формировании КП все данные копируются в историю вместе с
  готовым файлом. Изменения в реестре не меняют уже выданные КП.

## Возможности

**Новое КП**
1. Компания, ФИО руководителя, должность. Склонение («Иванову И.И.»,
   «Генеральному директору») и обращение «Уважаемый/Уважаемая …» подставляются
   автоматически (пол — по отчеству, можно выбрать вручную).
2. Услуги — поле с выпадающими подсказками из реестра (ищет по названию,
   ключевым словам, с опечатками). В одном КП может быть несколько услуг.
3. Справа — лист КП в виде документа. Любой текст правится прямо на листе:
   цена, сроки, этапы (добавить / удалить / переставить), сноски.
   Если цена отличается от реестра — появится отметка и галочка
   «Обновить цену в реестре».
4. «Сформировать КП» — скачивается .docx, КП сохраняется в истории.

**Реестр услуг (конструктор)**
- Карточка услуги: название, категория, ключевые слова, описание, срок, цена
  (числом или текстом), единица («единовременно», «ежемесячно», …),
  примечание, строка-группа, сноски, особые тексты КП.
- Детализация: таблица этапов со сроками, перестановка, вставка из Excel/Word.
- Справа — предпросмотр, как услуга будет выглядеть в КП.
- Импорт и экспорт Excel (листы «Услуги» и «Этапы»). Кнопка «Шаблон Excel»
  скачивает пустой файл с инструкцией. Экспорт → правка → импорт работает
  в обе стороны: строки с ID обновляют существующие услуги.

**История** — все КП: скачать, создать новое «на основе», поиск.

**Пользователи** — администратор добавляет сотрудников.

## Установка на сервер

Нужен Docker с Compose.

```bash
git clone <репозиторий> kp && cd kp
KP_ADMIN_PASSWORD='надёжный-пароль' docker compose up -d --build
```

Откройте `http://<сервер>:8000`, войдите как `admin` с этим паролем
и добавьте пользователей. Если пароль не задан — `admin`/`admin`,
смените его сразу (клик по имени в правом верхнем углу).

Все данные (база SQLite, история КП, ключ сессий) лежат в папке `./data` —
её достаточно регулярно копировать для резервной копии.

Для доступа по HTTPS поставьте перед приложением nginx/Caddy
(проксирование на порт 8000).

Обновление: `git pull && docker compose up -d --build`.

## Изменение фирменного бланка

Шаблон собирается скриптом из исходного файла
`backend/template_source/base_kp.docx`:

```bash
cd backend
python tools/build_template.py     # -> templates/kp_master.docx
```

Если поменялась шапка, адрес или подпись — замените исходный .docx
(структура должна остаться прежней) и пересоберите шаблон.

## Разработка

```bash
# бэкенд
cd backend
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt pytest httpx
uvicorn app.main:app --reload        # http://localhost:8000/api/docs
pytest

# фронтенд (в другом терминале)
cd frontend
npm install
npm run dev                          # http://localhost:5173, /api проксируется на :8000
```

Стек: FastAPI, SQLAlchemy (SQLite), docxtpl, pytrovich (склонение ФИО),
rapidfuzz (поиск), openpyxl; React + TypeScript + Tailwind.
